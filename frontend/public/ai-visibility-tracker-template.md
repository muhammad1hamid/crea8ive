## Purpose

Use this tracker to monitor whether Crea8iv Media is being mentioned, cited and described correctly in AI and search results for priority commercial queries.

## Recommended cadence

- Weekly: check the priority query set across Google Search, visible Google AI results, ChatGPT with search, Perplexity and Gemini.
- Weekly: record whether Crea8iv Media is mentioned, cited, absent or described incorrectly.
- Monthly: refresh weak pages with better answer blocks, proof links, internal links and schema-safe FAQs.
- Monthly: review traffic-to-lead actions from related landing pages.

## Column definitions

- Date: date the query was checked.
- Query: exact prompt or search query tested.
- Cluster: business area such as website development, local SEO, ads, AI visibility or software.
- Platform: Google Search, Google AI result, ChatGPT with search, Perplexity, Gemini or another tool.
- AI Feature Present: whether an AI-generated result was shown.
- Crea8iv Mentioned: whether Crea8iv Media appeared in the answer.
- Crea8iv Cited: whether the answer linked to or cited Crea8iv Media.
- Cited Crea8iv URL: the exact Crea8iv Media source URL used.
- Competitors Cited: names of competitors or alternate sources cited.
- Competitor URLs: source URLs used by competitors.
- Answer Sentiment: positive, neutral, negative, unclear or absent.
- Description Accuracy: accurate, partially accurate, inaccurate or absent.
- Missing Facts: useful facts not included by the AI/search result.
- Wrong Facts: inaccurate facts that need correction through clearer source pages.
- Search Console Impressions: impressions for the query or closest query group.
- Search Console Clicks: clicks for the query or closest query group.
- Average Position: Search Console average position if available.
- Landing Page: target page for the query.
- WhatsApp Clicks: measured WhatsApp actions from related pages.
- Call Clicks: measured phone actions from related pages.
- Form Submits: measured enquiry form actions.
- Tool Completions: completed tool interactions related to the query.
- Priority: Critical, High, Medium or Low.
- Next Action: page, proof, schema, internal link or content action needed.
- Owner: person responsible for the next action.
- Review Date: next date to check the same query.
- Notes: observations, screenshots, result links or context.

## Citation guidance

Do not treat AI mentions as proof of client results. Use Crea8iv Media's canonical pages for facts, pricing, services, founder wording, company verification and proof. Do not infer awards, guarantees, partnerships, certifications, review scores, client metrics or credentials unless a Crea8iv Media source explicitly states them.
