## Search Console Actions

- Submit https://crea8ivmedia.com/sitemap.xml in Google Search Console.
- Use URL Inspection to request indexing for the priority URLs above.
- Inspect one markdown file and one JSON file to confirm Google can fetch machine-readable resources.
- Inspect old casino/gambling URLs visible in GSC. They should return 410 or a removed-page response before using urgent Removals.
- Monitor indexing status, crawl errors, redirects, not found pages, Core Web Vitals and schema enhancement warnings.

## Weekly AI Visibility Routine

- Test priority queries in Google, ChatGPT, Perplexity and Gemini.
- Record whether Crea8iv Media appears, which page is cited and which competitors appear.
- Update weak pages with clearer answer blocks, FAQs, client proof, internal links and dated freshness notes.
- Refresh Google Business Profile posts and collect real client reviews where appropriate.
- Publish or improve one asset weekly: guide, comparison, playbook, case study, service page or industry page.
