# Crea8iv dual-market workflow

Read `docs/CREA8IV_DUAL_MARKET_AUDIT.md` from the repository root before changing design.

1. Identify market. Pakistan preserves its robot hero, established typography, orange/black identity, navigation and page composition. Qatar can be rebuilt with architectural media and connected-growth storytelling. Both retain logo, orange #FF6801, button/navigation family and company voice.
2. Preserve route catalogue, canonical URLs, real Arabic counterparts and truthful source-backed content. Use company.ts for facts and contacts. Never invent Qatar office/registration/phone, prices, metrics, testimonials or corporate portfolio attribution.
3. Keep SEO copy server-rendered and visible without animation/JavaScript. Keep client islands small. Avoid new dependencies. Qatar assets/runtime must not burden Pakistan pages.
4. Use logical CSS for Arabic, keyboard-operable controls, labelled forms, visible focus, meaningful image alternatives, explicit dimensions and reduced-motion fallbacks. No scrolling takeover or intro gate.
5. New generated media is concept illustration, never client proof. Inspect before integrating. Preserve real production attribution; stills are not videos.
6. Validate both markets at 375, 430, 768, 1024, 1440 and 1920. Check keyboard, no-JS, reduced motion, CTAs, field attribution, all Qatar metadata/links and Pakistan route preservation. Distinguish measured checks from unresolved production/editorial checks.
7. Preserve pre-existing workspace changes. Record exact changed files and limitations. Do not deploy, commit or push unless requested.
