# How Buyers Decide reference artwork

The three responsive cards follow the owner's supplied references. The first two
concepts use the three-card reference, and They Decide uses the separate trusted
connection reference. The section keeps the existing dark background and white
light-theme background. The cards retain their navy / pearl / navy palette in
both themes, with blue and orange accents and small dashed connecting arrows.

The illustrations were created with built-in image generation from the supplied
references. Card headings, badges and descriptions are live HTML. Production
images are optimized WebP files; the generated originals remain in the image
library. The complete prompt set and reference paths are in
[buyer-journey-reference.json](buyer-journey-reference.json).

- [They Find You artwork](../../frontend/public/img/homepage/buyer-journey/reference-find-v1.webp)
- [They Check You artwork](../../frontend/public/img/homepage/buyer-journey/reference-check-v1.webp)
- [They Decide artwork](../../frontend/public/img/homepage/buyer-journey/reference-decide-v1.webp)

Card labels use the site's Arial family in the bold reference style. Text and
spacing adapt to smaller cards, and the arrows turn downward when cards stack.
