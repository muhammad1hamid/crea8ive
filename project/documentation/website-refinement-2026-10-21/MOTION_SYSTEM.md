# Motion System

No new motion library or entrance effect. Existing hero motion remains unchanged. Basic control feedback uses 180ms colour/border transitions, without layout-changing hover dimensions.

Website project carousel buttons use instant movement under prefers-reduced-motion and smooth movement otherwise. Touch scrolling remains native. Interrupted pointer drags release transient state. Case-study rails remain keyboard-focusable named regions.

Reduced-motion verification and interaction tests are recorded in RESPONSIVE_QA.md. No blanket assertion that every legacy animation has been audited.
