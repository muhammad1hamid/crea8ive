# Design System Refinement

Preserve the existing Crea8iv logo, fonts and orange #ff6801. Shared brand tokens remain the identity source. Existing neutral surfaces and service tones remain authoritative; do not introduce a competing palette.

- Orange: primary business actions and selected brand accents, not every surface.
- Service colours: retain existing blue/web, teal/search, gold/ads, rose/brand and green/local mappings; never communicate meaning through colour alone.
- Typography: current installed families; fixed component heading sizes, body line-height 1.65 and zero added tracking. Full-width readable descriptions inside compact cards.
- Component radius: 8px; keep approved circular logos and existing hero button shapes.
- Surfaces: flat raised surfaces and visible borders for repeated compact items. No additional glow, glass layers or decorative images.
- Focus: visible, offset outline; minimum 44px command controls. Preserve native scrolling and browser zoom.
- Desktop: existing containers, three positioning items with full-width body copy. Mobile: existing horizontal carousel retained with a partial next item; no added long image stacks.
- New shared tokens: radius, reading leading and 180ms interaction duration. Use CSS Modules for owned refinements instead of adding another global override layer.

Design direction: an evidence-led marketing studio, not a dashboard or a new visual identity. Existing real project media remains the visual proof. Hero and primary SEO copy are deliberately unchanged pending a separately reviewed composition change.

## Sitewide Application

Use body-scoped modules for service/contact layouts, blog archive/reader, enquiries, location information and footer; shared surfaces alone are not a substitute for composition work. Preserve the existing differentiated process, comparison, editorial, evidence and form structures. Mobile diagnostic content uses a named keyboard-focusable swipe rail. Images with embedded copy use contain and no dark overlays; blog titles are also visible as normal text. Imported card decoration is removed only from the refined body components, not the hero. Market icons use existing service-tone families and must never overlap their labels.
